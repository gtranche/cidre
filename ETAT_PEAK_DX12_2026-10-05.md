## 1. PEAK / DX12 (session « PEAK/DX12 », la mienne)

**Objectif de départ atteint : PEAK démarre et est jouable.** La prémisse « crash dans la compilation des shaders (~20 min) » était FAUSSE.

**Vraie cause = deadlock W^X dans FEX/Wine** (prouvé lldb) : une page JIT de l'invité (Mono d'Unity) mappée `MAP_JIT` + le cache JIT de FEX aussi MAP_JIT → sur un seul fil, APRR ne peut pas être EXECUTE (fetch) et WRITE (store) en même temps → boucle infinie. (Les « morts à 20 min » = deux sessions qui se tuaient PEAK sur le prefix partagé.)

**Correctif (FAIT, 100 % Wine, sans toucher FEX — politique respectée)** dans `src/wine11/dlls/ntdll/unix/virtual.c` :
- Discriminant = `MEM_EXTENDED_PARAMETER_EC_CODE` (FEX marque DÉJÀ son propre code natif avec, l'invité non ; sonde confirmée : caches FEX 16 Mo = EC_CODE=1, heaps Mono = 0).
- `allocate_virtual_memory` : process émulé (main_image AMD64/I386) + exec+write + **PAS EC_CODE** + pas SEC_* → `vprot &= ~VPROT_EXEC` (page RW ordinaire, plus de MAP_JIT → plus de deadlock).
- `set_protection` : idem via `is_emulated_code(base)`.
- ⚠️ Ce changement est DANS l'arbre `src/wine11` (non commité, mêlé au reste du travail Wine non commité). **Détail complet** dans `note_peak_wx_fex.md` (à côté) et mémoire `project_cidre_peak_livelock_wx`.

**Deux autres pièces pour lancer PEAK :**
2. Lancer via `lancer_depuis_steam.sh` / `cidre play 3527290` (client Steam natif requis) — sinon `0xc06d007e` (SteamAPI_Init ne trouve pas le client).
3. **Défaut = DX11** (`d3d12=builtin` → E_NOINTERFACE → fallback DXVK D3D11, qui marche). Le `d3d12=n` du commit 629ebb6 n'était justifié que par le « deadlock builtin » = en fait le livelock W^X, corrigé.

**DX12 natif : PROUVÉ possible** (opt-in), voir §2.

**Reste ouvert sur PEAK : la PERF.** En jeu : **8-15 fps, GPU 100 %**, INSENSIBLE à : résolution (720p testé), TSO off (`CIDRE_TSO=0`), vsync off, compilation (async+cache). ⇒ **GPU barrier-bound** = efficacité KosmicKrisp (voir §3). Pas un réglage. (Note : `opt()` du launcher ne lit que `CIDRE_TSO=0/1`, pas `false` ; l'affichage « tso=true » est trompeur.)

**Modif registre faite** (réversible, `user.reg.bak-res`) : PEAK en fenêtré 1280×720 (le menu in-game cassait l'affichage winemac en Retina).
